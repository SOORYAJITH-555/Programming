# Bus Ticket Reservation System

A database project developed using **MySQL** with **PHP** as the backend.

## Description

This project is designed to manage bus ticket reservations efficiently. It allows administrators to manage buses, routes, schedules, bookings, and customer information while enabling users to book tickets.

## Technologies Used

- MySQL
- PHP

## Database Features

- Database creation
- Table creation
- Primary and Foreign Keys
- CRUD Operations
- SQL Joins
- Constraints
- Data retrieval using SELECT queriesv
