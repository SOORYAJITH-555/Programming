# JobPrepTool

## Overview

JobPrepTool is a group project developed as an Android application to help students prepare for campus placements by providing learning resources, programming practice, aptitude questions, interview preparation materials, and quizzes in a single platform.

The application aims to provide an organized and user-friendly environment for students to improve their technical and aptitude skills before placement drives.

---

## Features

- Programming learning resources
- Aptitude practice questions
- Technical interview preparation
- Multiple-choice quizzes
- User-friendly interface
- Firebase backend integration
