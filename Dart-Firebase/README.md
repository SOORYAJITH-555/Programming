# Dart & Firebase

## Overview

This folder contains projects and practice applications developed using **Dart**, **Flutter**, and **Firebase**. The projects demonstrate the development of cross-platform mobile applications with cloud-based backend integration.

## Technologies

- Dart
- Flutter
- Firebase

## Topics Covered

- Flutter UI Development
- Widget-Based Application Design
- State Management
- Navigation and Routing
- Form Validation
- Firebase Integration
- Authentication
- Cloud Database Integration
- Asynchronous Programming
- Mobile Application Development

## Purpose

The projects in this folder were developed to strengthen practical knowledge of Flutter application development and Firebase services while improving problem-solving, debugging, and software development skills.
