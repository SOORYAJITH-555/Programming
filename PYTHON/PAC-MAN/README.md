# Pac-Man Pathfinding Agent

## Overview

The Pac-Man Pathfinding Agent is a Python-based Artificial Intelligence project that demonstrates how classical search algorithms can be used to solve pathfinding problems in a maze environment.

The agent navigates through a 2D maze from the starting position to the target while avoiding walls and obstacles.

---

## Objective

To compare the performance of different AI search algorithms in finding an optimal path through a maze.

---

## Algorithms Implemented

- Depth First Search (DFS)
- Breadth First Search (BFS)
- A* Search Algorithm

---

## Features

- Interactive 2D maze visualization
- Intelligent pathfinding
- Real-time search visualization
- Performance comparison between algorithms
- Obstacle handling
- Optimal path generation

---

## Performance Metrics

The algorithms are compared based on:

- Path Length
- Nodes Expanded
- Execution Time

---

## Technologies Used

- Python 3
- Pygame
- Matplotlib (Performance Analysis)
